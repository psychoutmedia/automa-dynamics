# Automa Dynamics Landing Page

Futuristic corporate landing page for Automa Dynamics, deployed on Vercel.

## Tech Stack

- **Framework:** Next.js 14
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Deployment:** Vercel

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```

## Deployment to Vercel

1. Push this repo to GitHub
2. Import the project in Vercel (vercel.com)
3. Vercel automatically detects Next.js and deploys
4. Custom domain: Add `automadynamics.com` in Vercel project settings
